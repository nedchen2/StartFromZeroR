START FROM ZERO WITH R AND AI

Guide: https://nedchen2.github.io/StartFromZeroR/

1. Install R and RStudio using Chapter 0.
2. Extract the student ZIP. Open start-from-zero.Rproj in RStudio.
3. Open scripts/01-first-run.R. Use File > Save As to make
   scripts/my-01-first-run.R. Make the same kind of working copy for Chapters 2 and 3.
4. Lines beginning with # are comments. Lines beginning with # %% label blocks.
   Find the BLOCK named on the web page. Select its complete code and click Run.
5. Save your script with Ctrl/Cmd + S. Look for results in the outputs folder.
6. Restart R at the beginning of Chapters 2 and 3, then run the supplied blocks in order.

The data/practice_counts.csv file contains four invented milk samples.
The recorded counts are 10, 20 and 30 CFU/mL. The fourth count is missing.
The recorded-count mean is 20, with 3 recorded and 1 missing value.

Chapter 1 saves outputs/practice/first-run.txt.
Chapter 2 saves outputs/practice/known-counts.csv.
Its extension exercise writes a changed copy with mean 25 and no missing count.
Chapter 3 saves outputs/ch03/summary.csv and summary-check.txt.
Open outputs/ch03/ai-use-log.txt and record the route you used.

Sections 3.1-3.6 complete the main task using supplied AI replies and code.
Section 3.7 is an additional object-name error exercise.
Section 3.8 is optional live AI practice. Follow the AI access links in Chapter 1,
or complete the supplied code-inspection route.

Your finished work is a saved script, a checked summary CSV and a short log.
The optional templates/completion-card.txt helps you record what you completed.

If you get stuck, use Chapter 0's Get unstuck section. Copy your exact code
and the complete Console message when asking for help.
