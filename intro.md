# Your first R code with AI

**Machine Learning for Food Safety and Toxicology**

*Congjia Chen · Teaching assistant*

Start with an empty R script. Ask AI to write code, paste it into RStudio and run it. Then ask for one change and save your script.

You will use four **invented milk-sample counts** to make a small calculation and a bar chart.

| Step | What you do |
|---|---|
| [0. Install R and RStudio](chapters/00-start-here.md) | Install the two applications and open RStudio |
| [1. Ask AI for code](chapters/01-ask-ai.md) | Open HKU GenAI and send the supplied prompt |
| [2. Copy, paste and run](chapters/02-copy-and-run.md) | See a mean of 25 and a chart with four bars |
| [3. Change one thing and save](chapters/03-change-and-save.md) | Change the chart and save one R script |
