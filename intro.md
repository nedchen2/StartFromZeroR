# Start from zero with R and AI

**Machine Learning for Food Safety and Toxicology**

*Congjia Chen · Teaching assistant*

This short guide is for biology students starting with no programming experience. You will use R to inspect four invented milk-sample records, handle a missing measurement and check an AI reply against a calculation you can do by hand.

**[Begin with Chapter 0 →](chapters/00-start-here.md)**

## What you will do

| Chapter | Your result |
|---|---|
| [0. Start here](chapters/00-start-here.md) | Install R and RStudio and learn where to run code |
| [1. Your first successful run](chapters/01-first-run.ipynb) | Save an R script and create a text file |
| [2. The R you need today](chapters/02-minimum-r.ipynb) | Read four rows, find a missing count and save a CSV |
| [3. Ask, run, inspect and repair](chapters/03-working-with-ai.ipynb) | Check a proposed summary, repair it and save your evidence |

Work through the guide at your own pace. The supplied examples, expected outputs and checks support self-study. Live AI activities are optional. You can complete the guide by running and inspecting the supplied R code.

## Why I wrote this guide

An AI reply can produce code quickly. Understanding what that code does takes practice. With just four records, you can compare the output with your own calculation and see how a small assumption changes the answer.
